# Контекст проекта для Claude

## Что строим
Сервис бизнес-анализа для любых бизнесов, которые хотят расти. Клиент отвечает на вопросы в Telegram-боте, получает по ссылке страницу с майндкартой бизнеса, BPMN-схемами процессов и узкими местами. Рекомендации — позже.

## Модель бизнеса (решено)
- Старт: гибрид — бесплатный экспресс-разбор как воронка + платный разбор «ИИ + эксперт» (владелец проверяет результат).
- SaaS по подписке — только когда процесс отточен.
- Интерфейс: Telegram-бот (интервью) + веб-страница отчёта.

## Технические решения
- Python. Нейронка — сменный модуль: API сейчас нет, на старте ответы клиента разбираются вручную через Claude.
- Всё строится из единой модели `schema/business_model.schema.json`. Анкета — `schema/questionnaire.yaml`.
- BPMN генерируется кодом из JSON (не нейронкой напрямую), раскладка своя в `core/bpmn.py`: дорожки = роли, колонки = длиннейший путь, ветки развилок — отдельные ряды, циклы идут понизу.
- Отчёт — один HTML, markmap и bpmn-js с CDN.

## Стиль
- Общение с владельцем: на «ты», по-дружески, без воды; решения — 2–3 варианта с плюсами и минусами.
- Тексты для клиентов — простым языком, без канцелярита.
