# Картинки бота

В фирменном стиле сайта lukyanovich.tech: ночной фон, светящаяся сфера с кольцом, шрифты Unbounded и Manrope, фиолетовый и персиковый.

| Файл | Где используется |
|---|---|
| `icon.png` (640×640) | аватар бота — поставлен через Bot API (`setMyProfilePhoto`), можно и вручную в @BotFather: `/setuserpic` |
| `finish.jpg` (1280×720) | последнее сообщение бота: «Спасибо! Разбор уже в работе» и шаги, что дальше |
| `welcome.jpg` (1280×720) | первое сообщение бота: картинка с приветствием в подписи. Можно поставить и как картинку описания в @BotFather (Edit Bot → Edit Description Picture) — её видно до нажатия «Старт» |

## Как перерисовать

Тексты и цвета — в `make.html`. Запустить сервер и открыть страницу — картинки сохранятся сюда же:

```bash
python assets/bot/serve.py
```

Дальше открыть http://localhost:8766/make.html, дождаться надписи «Готово» и остановить сервер.
